## 決めたこと
- 2026-11-04: 自分の名字を世界中に広めて、全員を同じ名字にするゲームを作る。感染が広がるタイプのシミュレーションの雰囲気で、しくみ（広がる → 強化する → じゃまが入る）だけ借りる
- 2026-11-04: Unity 6000.4.0f1 で作る。1人で制作する。リポジトリは `myouzi-world1`（同時に作った `myouzi-world` は使わない。消さずに残す）
- 2026-11-04: 2D ゲームにする（Unity のテンプレートは「Universal 2D」）
- 2026-11-04: 広める名字はゲームの最初にプレイヤーがキーボードで入力する（決まった名字は無い）
- 2026-11-04: Unity プロジェクトはリポジトリの中の `My project/` フォルダに置く（将棋と同じ形）。`.gitignore` はサブフォルダでも効く形
- 2026-11-04: 最初の画面は名字を入力する画面。タイトル「名字ワールド」（仮）、入力欄、「この名字で始める」ボタン。Enter でも決定できる（日本語の変換を確定する Enter では決定しない）
  - 名字は前後の空白を取って 1〜8 文字（8 文字は仮）。前回入れた名字を覚えていて、次に起動したとき入力欄に入れておく
  - 決めたあとは「世界に「〇〇」を広めよう！」と出す仮の画面。この先のゲームはまだ無い
  - 画面は Unity の UI（Canvas）をプログラムで作る。文字は Windows の日本語フォント（Yu Gothic UI など）。`Assets/Resources/UIFont/` にフォントを置けばそれを使う
- 2026-11-04: 作業のルールは `CLAUDE.md` に、決めたことはこのファイルに書く（将棋ゲームのものを土台にした）
